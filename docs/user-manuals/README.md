# TechCart User Manuals

End-user guides for the two TechCart applications — the **Buyer App** (the
storefront shoppers use) and the **Admin App** (the console staff use).

The full manuals are maintained **in the TechCart repository**, next to the code
they document, and render there with their screenshots:

- **Buyer App manual** — <https://github.com/Pravin671231/TechCart/blob/main/docs/user-manuals/buyer-app.md>
- **Admin App manual** — <https://github.com/Pravin671231/TechCart/blob/main/docs/user-manuals/admin-app.md>

This folder keeps a stable entry point and a short per-app summary that links
straight into the relevant sections of the live documents.

| Manual                       | Audience                       | Covers                                                                                             |
| ---------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------- |
| [buyer-app.md](buyer-app.md) | Shoppers using the storefront  | Sign-in, browsing, search, filters, product details, cart, checkout & payment, orders, account   |
| [admin-app.md](admin-app.md) | Staff using the admin console  | Sign-in, console layout, dashboard, catalog setup, inventory, orders & refunds, admin users       |

The manuals are screenshot-heavy and change alongside the apps, so they are not
duplicated here — follow the links above for the illustrated originals.
