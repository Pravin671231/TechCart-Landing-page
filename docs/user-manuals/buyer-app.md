# Buyer App — User Manual

The TechCart storefront is where shoppers browse the catalogue, manage a cart,
check out, and track orders. It runs in any modern browser on desktop or mobile.
Browsing is public; an account (Google or email one-time code — no password) is
needed only to use the cart, check out, view orders, or manage a profile.
